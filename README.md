# Fellipe Gonçalves Leite

Student at CEFET-MG in Brazil. I build web and mobile apps, and I'm working on a research project that maps the South Atlantic Anomaly from public NOAA satellite data.

## Some things I've built

- **[human-nomad-simulator](https://github.com/fellipegoncalvesleite/human-nomad-simulator)** — a browser simulation of nomadic bands that migrate, remember useful places, split when they grow too large, and leave behind wiki-style histories. TypeScript core, React and canvas front end.
- **[saa-poes-mapping](https://github.com/fellipegoncalvesleite/saa-poes-mapping)** — mapping the South Atlantic Anomaly from NOAA POES/MetOp SEM-2 data, with sensitivity analysis across thresholds, channels, and satellites.
- **[nobre-amor-baby](https://github.com/fellipegoncalvesleite/nobre-amor-baby)** — a real baby-clothes online store with catalog, checkout, shipping, customer accounts, and admin tools. React, Vite, Supabase.
- **[versus-quiz](https://github.com/fellipegoncalvesleite/versus-quiz)** — a real-time multiplayer typing quiz where players share a private room and race to claim the correct answer. Next.js and Supabase Realtime.
- **[bebecare](https://github.com/fellipegoncalvesleite/bebecare)** — a Flutter app for baby routines, growth, vaccines, and bedtime stories.
- **[satvocab](https://github.com/fellipegoncalvesleite/satvocab)** — a browser game for practicing SAT vocabulary with several question modes and local progress tracking.

Mostly working with Flutter, React/TypeScript, and Python.
